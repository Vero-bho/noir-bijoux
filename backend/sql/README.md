# Скрипты базы данных MSSQL (альтернативный вариант)

> **Основная база проекта — PostgreSQL в облаке Supabase**, скрипты для неё лежат
> в папке `backend/sql-postgres/` (см. `docs/ШАГ-5b_База_данных_Supabase.md`).
> Эта папка сохранена для варианта MS SQL Server: пригодится, если в отчёте нужно
> сравнить две СУБД. Текущее подключение бэкенда настроено на PostgreSQL.

Порядок выполнения — по номерам. Выполнять в **SQL Server Management Studio**
(открыть файл → F5) или через **sqlcmd** (примеры — в комментариях к файлам).

## Быстрый старт: один файл вместо шести

Нужно просто создать базу и таблицы «с нуля»? Откройте **`00_create_all_simple.sql`**
в SSMS и нажмите **F5**. Этот единственный файл содержит всё по порядку:

1. создание базы `noir_bijoux`;
2. 12 таблиц (с комментарием к каждому полю);
3. 12 связей между таблицами;
4. 13 индексов;
5. запрос проверки «сколько строк в каждой таблице».

Типы данных — только простые: `INT`, `DECIMAL(10,2)`, `NVARCHAR(n)`, `DATETIME`, `BIT`.
Внизу файла закомментированы блок удаления базы и создание отдельного
пользователя `noir_app` — если он понадобится.

Данные магазина этот скрипт не вставляет — для них выполните `04_seed.sql`.
Полный вариант по шагам (с проверками и откатом) — скрипты 01–06 в таблице ниже.

| № | Файл | Что делает | Повторный запуск |
|---|---|---|---|
| 01 | `01_create_database.sql` | создаёт базу `noir_bijoux`, логин `noir_app`, выдаёт права | безопасен |
| 02 | `02_schema.sql` | создаёт 12 таблиц и 12 связей | ошибка «уже существует» — это нормально |
| 03 | `03_indexes.sql` | добавляет 13 индексов по внешним ключам | безопасен |
| 04 | `04_seed.sql` | заполняет базу данными магазина | безопасен (сначала очищает таблицы) |
| 05 | `05_verify.sql` | 11 запросов проверки — для отчёта и скриншотов | можно в любой момент |
| 06 | `06_drop_database.sql` | удаляет базу целиком (начать заново) | безопасен |

## Как создаются файлы 02 и 04

Их не пишут руками, а генерируют из схемы и данных проекта:

```bash
python3 _tools/generate_sql.py        # 02_schema.sql + миграция Prisma
python3 _tools/generate_sql_seed.py   # 04_seed.sql (данные из frontend/app/data)
```

* `02_schema.sql` — тот же сгенерированный Prisma T-SQL, что лежит в
  `src/prisma/migrations/20261006120000_init/migration.sql`;
* `04_seed.sql` — те же данные, что вставляет `npm run seed` (файл `src/prisma/seed.ts`).

## Проверка без SQL Server

Структуру и данные SQL-скриптов можно проверить, не устанавливая MSSQL:

```bash
npm run test:sql
```

Скрипт сверяет таблицы и связи со `schema.prisma`, проверяет ссылочную
целостность данных, суммы заказов, bcrypt-хеши паролей и совпадение данных
с сайтом (49 проверок).
