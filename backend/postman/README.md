# Коллекция Postman — Noir Bijoux API

В папке два файла для импорта в Postman:

| Файл | Что это |
|---|---|
| `Noir-Bijoux.postman_collection.json` | 37 запросов ко всем эндпоинтам API (9 папок) |
| `Noir-Bijoux.postman_environment.json` | окружение: `baseUrl = http://localhost:4000` и демо-доступы |

Файлы генерируются скриптом `_tools/build_postman.py` из корня проекта — если
меняются маршруты, правьте скрипт и запускайте его заново, а не JSON вручную.

## Как импортировать

1. Открыть Postman → **Import** → перетащить оба файла (`Ctrl+O`).
2. В правом верхнем углу выбрать окружение **Noir Bijoux — локальный сервер**.
3. Запустить бэкенд: `npm run dev` (или `npm run demo` — без SQL Server).

## Порядок работы с коллекцией

Запросы сгруппированы по папкам и рассчитаны на последовательный запуск:

| Папка | Что проверяет |
|---|---|
| 1. Сервис | сервер поднят, база отвечает, Swagger отдаёт описание |
| 2. Авторизация | регистрация, вход, текущий пользователь, вход администратора |
| 3. Каталог | изделия, фильтры, карточка по slug, категории, материалы |
| 4. Конструктор | компоненты, сохранение сборки, «мои сборки», удаление |
| 5. Избранное | добавить сборку в избранное, список, удалить |
| 6. Доставка | точки самовывоза и пункты выдачи |
| 7. Заказы | оформление (самовывоз/курьер), история, заказ по номеру, смена статуса |
| 8. Личный кабинет | профиль, правка данных, загрузка аватара, смена пароля |
| 9. Администрирование | добавление, изменение и скрытие изделия, все заказы магазина |

Коллекция сама передаёт данные дальше: после «Входа» JWT попадает в переменную
`token`, после сохранения сборки — `buildId`, после оформления заказа —
`orderNumber`. Поэтому защищённые запросы работают без ручной вставки токена.

Кнопка **Run collection** прогоняет всё подряд и показывает отчёт по проверкам
(вкладка Tests в каждом запросе).

## Два замечания

* **Загрузить аватар** — единственный запрос, где нужно выбрать файл вручную:
  Body → form-data → поле `avatar` → Select File (JPG, PNG, WEBP или GIF до 3 МБ).
* **Сменить пароль** меняет пароль демо-пользователя на `noir5678`. Если
  запускаете коллекцию повторно, верните пароль обратно или поменяйте значение
  переменной `password` в окружении.

## Автоматический прогон без Postman

Ту же коллекцию можно выполнить из консоли — она запускается движком Newman
на встроенной in-memory базе (SQL Server не нужен):

```bash
npm run test:postman
```

Ожидаемый результат: `запросов выполнено: 37`, `успешно 37, ошибок 0`.
