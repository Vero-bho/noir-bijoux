# Папка docs — описания API (Swagger)

По умолчанию документация Swagger собирается из JSDoc-комментариев в файлах
`src/modules/**/*.routes.ts` (см. `src/config/swagger.ts`).

Если по методичке (занятие 5) требуется хранить описание эндпоинтов в отдельных
YAML-файлах — положите их в эту папку (`auth.yaml`, `products.yaml`, ...).
Файлы подхватываются автоматически: в настройках `swagger-jsdoc` уже указан
шаблон `./docs/*.yaml`.
